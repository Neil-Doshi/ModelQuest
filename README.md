# ModelQuest

A mobile-friendly, game-like machine-learning learning world built around real mechanical-engineering examples.

The course progresses through 13 model quests, from industrial sensor calibration and predictive maintenance to Transformers, LoRA, and a final engineering RAG copilot. Lessons connect interactive visuals, theory, math, code, real-world failure modes, GitHub, Hugging Face, and free-first Google Colab workflows.
